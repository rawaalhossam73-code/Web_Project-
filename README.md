# Hot Tech Deals - متجر إلكتروني تقني 

توثيق المشروع النهائي لمساق تطوير الويب. 

# وصف المشروع

هو عبارة عن واجهة مستخدم لمشروع Hot Tech Deals متجر إلكتروني متخصص في عرض أحدث المنتجات التقنية. تم بناء وتطوير هذا الموقع بالاعتماد على تقنيات الويب الأساسية لتقديم تجربة مستخدم سلسة وتصميم عصري يتناسب مع كافة الشاشات (Responsive Design). 

#  فكرة المشروع 

تتمثل فكرة المشروع في تصميم واجهة متجر تفاعلية تحقق المعايير البرمجية التالية:
1. **بناء هيكل تنظيمي**: استخدام لغة HTML5 لضمان تنظيم الكود برمجياً وتسهيل مراجعته وتطويره.
2. **تنسيق احترافي**: الاعتماد على CSS3 وتقنيات التوزيع الحديثة (مثل Flexbox) لضمان مرونة التصميم وتجاوبه الكامل.
3. **إضافة ميزات تفاعلية**: استخدام JavaScript لبرمجة وظائف المتجر، مثل إضافة المنتجات إلى سلة التسوق وتحديث العداد ديناميكياً. 

# الأدوات والتقنيات المستخدمة 

تم إنجاز هذا المشروع بالاعتماد على الأدوات والبرمجيات التالية:
- **HTML5**: لغة هيكلة محتوى الويب.
- **CSS3**: لغة تنسيق وتصميم صفحات الويب.
- **JavaScript**: لغة البرمجة التفاعلية.
- **Acode**: بيئة التطوير المستخدمة لتحرير وكتابة الشفرات البرمجية.
- **GitHub**: لإدارة النسخ ورفع التعديلات وتوثيق المشروع.
